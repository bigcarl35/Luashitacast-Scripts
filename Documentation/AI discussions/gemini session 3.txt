    To track specific Phantom Rolls in Luashitacast (since action.Name only returns "Phantom Roll"), you can intercept the outgoing packet or read the specific roll name using Ashita's chat
    or packet listeners.

    However, the cleanest and most reliable way within a standard Luashitacast profile is to hook into gData.GetAction() before the cast finishes or use an Ashita event packet listener inside
    your profile to set a variable.

    Here is how you can set up a variable to track the last used specific roll and use it for your gear swaps.

    Step 1: Initialize the Variable

    At the very top of your Luashitacast script (outside of any functions), create a variable to hold the name of the current roll.

        local currentRoll = 'None';

    Step 2: Intercept the Roll Name via Packet or Chat

    Since action.Name defaults to "Phantom Roll" when the command is sent, we can look at the outgoing command text or hook the command itself to see exactly what the player typed (e.g.,
    /ja "Chaos Roll" <me>).

    Add this Ashita event handler to the top of your script to catch the command before Luashitacast processes the generic action:

        -- Track the specific roll command typed by the player
        ashita.events.register('command', 'track_rolls', function(cmd, nType)
            local args = cmd:args();
            if #args >= 2 then
                -- Check if the player is using a job ability command
                if args[1]:lower() == '/ja' or args[1]:lower() == '/jobability' then
                    local abilityName = args[2]:gsub('"', ''):lower(); -- Remove quotes and lowercase

                    -- If it looks like a roll, save it to our variable
                    if abilityName:find('roll') then
                        currentRoll = abilityName;
                    end
                end
            end
            return false;
        end);

    Step 3: Use the Variable in your HandleAbility Logic

    Now that currentRoll updates whenever you type or macro a roll, you can check it inside your profile.HandleAbility() block.

        profile.HandleAbility = function()
            local action = gData.GetAction();

            -- Generic check for any Phantom Roll
            if (action.Name == 'Phantom Roll') then
                -- 1. Equip your baseline roll gear (e.g., Luzaf's Ring, Corsair's Tricorne)
                gFunc.EquipSet(sets.PhantomRoll);

                -- 2. Specific swaps based on the exact roll we intercepted
                if (currentRoll == 'blitzers roll') then
                    gFunc.Equip('Legs', 'Chocobo Hose'); -- Example specific item swap
                elseif (currentRoll == 'tacticians roll') then
                    -- Equip specific gear for Tactician's
                end

            -- Handle Double-Up safely
            elseif (action.Name == 'Double-Up') then
                gFunc.EquipSet(sets.DoubleUp);
            end
        end;

        end;
